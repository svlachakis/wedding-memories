Γεια σας αγαπημένοι μου…

Μπορεί να μην έχουμε γνωριστεί ακόμα από κοντά, μπορεί να μην έχετε ακούσει τη φωνούλα μου, ούτε να έχετε νιώσει τα μικρά μου χεράκια να σας αγκαλιάζουν…

Όμως θέλω να σας πω ένα μεγάλο μυστικό…

Είμαι εδώ! Μεγαλώνω σιγά σιγά μέσα στην κοιλίτσα της μανούλας μου, εκεί που ακούω την καρδούλα της να χτυπά και νιώθω ήδη τόση αγάπη.

Έρχομαι κοντά σας, για να κάνω την αγάπη σας ακόμα μεγαλύτερη, τις αγκαλιές σας ακόμα πιο ζεστές και την οικογένειά μας ακόμα πιο όμορφη.

Δεν ξέρω ακόμα αν θα σας μοιάζω, αν θα έχω τα μάτια σας ή το χαμόγελό σας… Ξέρω όμως πως είμαι ήδη πολύ τυχερό που σας έχω.

Κρατήστε μου μια αγκαλιά, ένα φιλάκι και μια θέση στην καρδιά σας…

Γιατί σε λίγους μήνες θα είμαι εκεί, για να σας γνωρίσω από κοντά και να σας αγαπήσω όσο με αγαπάτε ήδη.

Ετοιμαστείτε… γιατί η οικογένειά μας μεγαλώνει!

Με όλη μου την αγάπη, το μικρό σας θαυματάκι που ανυπομονεί να σας συναντήσει. 👶❤️
